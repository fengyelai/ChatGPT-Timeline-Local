# Security and privacy reports

Please **do not** paste account passwords, API keys, cookies, session tokens, live conversation contents, private ChatGPT URLs or personal information into a public issue.

To report a reproducible issue, share the browser/version, extension version, expected versus actual behavior, and a sanitized diagnostic or screenshot. Use a synthetic ChatGPT conversation where possible.

This v0.1.0 preview runs as an unpacked extension with a narrow declared permission surface. Security review and actual browser acceptance remain the responsibility of the user before installation on sensitive accounts.
