找回长对话里的每次提问

右侧短横线导航、提问预览、关键词搜索和可停止的历史扫描。

本包已完成模拟 DOM 测试；尚未在你的实际 ChatGPT 账户和 Edge 扩展环境验证。先安装试用，再以真实跳转结果验收。

安装到 Edge / Chrome

  1. 解压 ZIP 到一个固定文件夹。
  2. 在地址栏输入 edge://extensions/ 或 chrome://extensions/。
  3. 打开“开发人员模式 / 开发者模式”，点击“加载解压缩的扩展”。
  4. 选择本包中的 extension 文件夹，该文件夹内直接包含 manifest.json。
  5. 刷新 ChatGPT 对话网页，点右侧“目录”。长对话再点“扫描历史”。

首次验收建议暂时停用其他修改 ChatGPT 时间线或滚动的扩展。扫描时，点“停止”、滚轮或 Esc 都可以中断。

若目录为 0 或跳转失败

点击“诊断”，Ctrl+C 复制诊断文本，连同界面截图反馈。诊断不含正文、会话 ID、Cookie 或令牌。

“已索引”不代表已经读取全部历史；首版不生成真实提问时间，索引刷新后会重建。只支持浏览器网页，不能直接用于原生桌面客户端。
