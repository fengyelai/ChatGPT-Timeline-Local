# 对话时间线 Local · 0.1.0 试用版

为 Edge / Chrome 的 ChatGPT 网页添加右侧短横线导航。每条对应一次已识别的用户提问；悬停预览，点击定位，展开目录后搜索。

**交付状态：源码、安装包和离线演示已经完成；模拟 DOM 测试报告见 `tests/results.json`。尚未经过用户真实 ChatGPT 账户、实际 Edge/Chrome 扩展加载的验证，不能称为已保证兼容的正式版。**

## 安装（无需 API、无需 Node、无需编译）

1. 解压整个 ZIP，放到一个以后不会随意删除的文件夹。
2. 在 Edge 地址栏输入 `edge://extensions/`；Chrome 输入 `chrome://extensions/`。
3. 打开“开发人员模式 / 开发者模式”。
4. 点击“加载解压缩的扩展 / 加载已解压的扩展程序”。
5. 选择本包内的 **`extension` 文件夹**，里面直接包含 `manifest.json`。
6. 刷新一个 ChatGPT 对话网页。页面右侧应出现“目录”和短横线。

请先暂停其他会修改 ChatGPT 时间线、消息隐藏或滚动行为的扩展，再完成第一轮对照验收。此举只用于排除冲突；无需清除 Cookie 或重新登录。

安装方式依据：[Microsoft Edge 官方说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)。

## 使用

| 入口 | 行为 |
|---|---|
| 右侧短横线 | 悬停显示提问摘要；点击跳转 |
| 目录 | 展开可搜索的提问列表 |
| 搜索框 | 搜索本标签页已经索引的提问 |
| 扫描历史 | 主动滚动当前对话，收集可加载的较早消息，再尝试恢复原位置 |
| 停止 / Esc / 手动滚轮 | 停止自动滚动并保留已收集的索引 |
| 重建索引 | 清除本标签页的旧索引；切换回答分支后建议使用 |
| 诊断 | 显示结构与滚动信息，选中后可 Ctrl+C；不包含对话正文或会话 ID |
| ⇄ | 将插件移到另一侧，避开现有界面 |
| ↓ | 返回当前可滚动内容的底部 |
| Alt+Shift+T | 展开 / 收起目录；如快捷键冲突，直接点“目录” |

这里的 timeline 表示**提问顺序**。序号是已索引条目的顺序，不冒充全对话的绝对轮次，不生成虚假的提问时间。

## 长对话的边界

- ChatGPT 可能只在 DOM 中挂载临近视口的消息。没有出现在页面里的内容，初始索引无法直接知道。
- “扫描历史”通过正常滚动触发页面加载；每轮最多 90 秒，索引最多 4000 条。达到上限会明确提示。
- 到达当前可滚动区两端，仍不等于证明历史全部加载完毕。网络延迟、折叠内容、灰度界面和列表实现都会影响覆盖率。
- 扫描完成后仍可继续阅读、滚动和再次扫描。正文索引仅保存在当前标签页内存，刷新后需要重新建立。
- 使用消息/轮次标识区分同文提问；没有稳定标识的节点只在其仍挂载时收录，避免将相同文字误合并。
- 只处理当前看到的分支，不合并所有被编辑或重新生成的历史分支。对同一路径下发生的复杂分支切换，本版需要手动“重建索引”。
- 一次远端定位最多尝试约 14 秒。必须重新发现目标节点并检查其已进入可视区域，才显示“已定位”；失败会给出明确提示。
- 自动扫描会滚动页面，生成回答期间建议暂不扫描。

## 为什么采用这个方案

2026-10-02 检索发现，维护者近期已针对 ChatGPT 虚拟列表及反向滚动进行适配：

1. [GPT-Conversation-Toolkit v1.4.4 说明](https://github.com/bujue3709/GPT-Conversation-Toolkit/blob/main/README.en.md)：2026-09-29 的更新明确涉及新版反向滚动下时间线跳转失败。维护者说明，长对话存在消息挂载/卸载行为。
2. [该项目的 DOM 适配源码](https://github.com/bujue3709/GPT-Conversation-Toolkit/blob/main/utils/dom.js)：展示新版气泡/轮次标识与旧版消息角色结构的差异。这里用它核实结构变化，交付代码独立编写。
3. [houyanchao/chatgpt-gemini-timeline](https://github.com/houyanchao/chatgpt-gemini-timeline)：已有多平台时间线、问题列表等完整产品，是否适用于用户当前账户仍需实测。
4. [Chrome content scripts 文档](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)：浏览器扩展可通过隔离的内容脚本读取页面 DOM 并添加控件。
5. [MDN scrollTop 文档](https://developer.mozilla.org/en-US/docs/Web/API/Element/scrollTop)：反向列布局中的 `scrollTop` 可以为负数，不能一律按普通正向滚动处理。

以上是公开项目的维护记录与技术依据，不是对用户当前页面故障的现场诊断；没有证据证明所有现有扩展当前均已失效。

本版选择 **Manifest V3 + 本地 DOM 适配 + Shadow DOM 界面 + 内存索引 + 可取消定位/扫描**，把兼容问题集中在可维护的适配层。首版不依赖未公开的会话 API，不读取 Cookie、会话令牌或访问令牌。

## 开发规划与验收门槛

### 阶段一：本地试用版（本次交付）

已实现：提问短横线、列表与搜索、新旧 DOM 适配、当前节点指示、同文多消息区分、历史扫描、反向滚动、切换会话清理、失败诊断、左右换位、基础深色样式。

已验证：语法、模拟 DOM、模拟虚拟列表和滚动几何。未验证：真实浏览器渲染、真实扩展加载、真实账户页面、完整 ChatGPT 分支行为及性能。

### 阶段二：校准当前账户（下一步最重要）

在用户实际 Edge 上使用三段对话：短对话、100 轮以上长对话、含图片/文件或编辑分支的对话。

| 验收项 | 通过标准 |
|---|---|
| 可见性 | 打开/刷新/站内切换后出现一个时间线，无重复浮层 |
| 识别 | 逐项抽查至少 10 条，只收录用户提问，不收录输入草稿与回答 |
| 跳转 | 抽查首部、中段、末尾各 3 个目标，实际落在对应提问 |
| 虚拟列表 | 已索引消息被卸载后仍能在目录看到，并能重新加载定位 |
| 不误报 | 找不到目标时明确失败；未确认完整历史时不显示“全部” |
| 会话隔离 | A→B→A 不混入另一会话内容；编辑或换分支后可重建 |
| 阅读体验 | 中文长问题可预览，窄窗口、125%/150%缩放、深浅色可读，控件不挡输入 |
| 可控性 | 扫描中滚轮/Esc/停止按钮可中断，输入和发送功能正常 |

若失败，优先提供插件“诊断”文本及界面截图；如果仍不足，再截取一条非敏感测试消息的结构信息。**不需要登录密码、Cookie、令牌、完整历史导出或完整网页源代码。**

### 阶段三：正式可维护版（实测通过后）

- 增加具体页面结构的回归样本，包括用户实际使用的 Work 页面；网页版本与桌面客户端分别定义支持范围。
- 完善同一路径内切换分支的自动失效检测、慢加载重试和长答案间隔中的定位。
- 在保留扫描兜底的前提下，评估是否需要“完整当前分支索引”的数据来源；若涉及内部接口，必须单独适配、单独标记不稳定性，不将其称为公开 ChatGPT API。
- 然后再增加收藏、备注、可选本地持久化和备份导出。默认正文不落盘的规则如改变，应在产品中说明。
- 建立版本更新/回退说明。若需要商店发布，再整理图标、隐私说明、兼容性记录；本包未发布到任何商店。

## 隐私与权限

- 扩展只注入 `https://chatgpt.com/*` 和旧域名 `https://chat.openai.com/*` 的顶层网页。
- `storage` 仅保存左右侧位置；提问文本只存在标签页内存。
- 没有服务器、统计追踪、远程 JavaScript、API key 或外发网络请求。
- 读取页面已经渲染的用户消息；不读取登录信息，不改变用户提问/回答，不自动发送消息。
- 搜索只查已索引的提问，本版不搜索回答全文，不扫描其他会话。
- 这是独立开发的浏览器扩展，不是 OpenAI 官方插件；不能直接嵌入原生桌面应用。

## 更新、移除和回退

本次测试环境无法下载可用的测试浏览器，云浏览器也不允许打开本地演示 URL，故保留了上述真实浏览器验收限制，没有将模拟测试包装为实际账户实测。
